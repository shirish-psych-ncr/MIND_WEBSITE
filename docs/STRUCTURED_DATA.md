# Structured data ownership

The clinic's shared entity graph is generated by `src/components/StructuredData.astro` from facts in `src/config/business.ts`. `src/layouts/Layout.astro` renders it once in every page head.

Use these stable identities:

- Clinic: `https://mindgracencr.in/#clinic`
- Physician practice: `https://mindgracencr.in/#physician`
- Dr Anita Sharma as a person: `https://mindgracencr.in/#doctor-anita-sharma`
- Website: `https://mindgracencr.in/#website`

Page-specific FAQ, article, service, and breadcrumb JSON-LD may stay with the page. Refer to a shared entity by `@id`; do not redefine it, nest an incomplete physician under the clinic, or add structured data from client-side JavaScript.

After changing business facts or schema, run `npm run check`. The build stage validates every generated JSON-LD block, checks that each page has one complete clinic definition, checks the doctor page's Person and Physician nodes, and rejects retired Amplitude runtime references.

For a browser console smoke test, serve `dist` at `http://127.0.0.1:8765` and run `npm run audit:console`.
