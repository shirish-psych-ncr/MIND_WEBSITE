# Mind Grace Interactive Tools - LLM Context File

Part of https://mindgracencr.in/ (see /llms.txt for clinic-wide usage rights).

## Purpose
Free browser-based grounding and calming tools from Mind Grace Neuropsychiatric
Clinic, Greater Noida. Each tool page carries a "What this tool does" summary.

## Tools
- Butterfly Tapper (bilateral grounding): https://mindgracencr.in/toolsbutterfly-tapper
- Guided Breathing (anxiety, panic, sleep): https://mindgracencr.in/toolsguided-breathing
- Lateral Grounding (eye-movement): https://mindgracencr.in/toolseye-movement
- Horizon Scanning (visual grounding): https://mindgracencr.in/toolshorizon-scan
- Grounding Fractal: https://mindgracencr.in/toolshypnos-fractal
- Leaf on Stream (thought defusion imagery): https://mindgracencr.in/toolsleaf-on-stream

## Safety note
These are routine stress-support exercises, not treatment. All pages carry crisis
guidance; users in distress are directed to professional support.
